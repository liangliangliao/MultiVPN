# 路线图与验收条件

## 已完成 V0.1
- [x] Android Kotlin/Compose 工程
- [x] 常见代理节点链接识别
- [x] WireGuard / OpenVPN 配置文件解析
- [x] 加密本地储存与删除确认
- [x] 中国大陆直连、主力、备用的**仅配置**偏好
- [x] 单元测试和 Debug APK 构建工作流
- [ ] 真实 VPN 连接 —— 不属于 V0.1

## V0.2：第一条真实 VPN 隧道
- [ ] 固定并记录可复现的 sing-box/libbox Android 版本与许可，禁止动态下载未知可执行二进制。
- [ ] 在已授权的 Android VpnService 中建立 TUN、配置排除应用与受保护的底层 socket。
- [ ] 安全映射 Hysteria 2 和 Shadowsocks 配置，确保机密仅在进程内使用。
- [ ] 用户操作一键连接/断开，真实连接状态来自底层核心。
- [ ] 飞行模式、移动网络/Wi-Fi 切换、屏幕锁定、进程回收、连接失败的真实设备测试。
- [ ] IPv4、IPv6、DNS 防泄漏与直连回退行为测试。
- [ ] 至少一台真实 Android 设备完成连通、DNS 和故障模拟验证。
- [ ] 只有全部验收通过才可以在 UI 显示“连接可用”。

## V0.3：代理核心丰富化
- [ ] VLESS、VMess、Trojan、TUIC、AnyTLS、WireGuard（评估可用的具体引擎）。
- [ ] 配置订阅解析：支持真实格式并完整测试 token 安全。
- [ ] 节点延迟和可用性探测（明确测试目标与采样方式）。
- [ ] URI/二维码导入、冲突名称与重复检测。

## V0.4：传统 VPN
- [ ] OpenVPN UDP / TCP，含用户名密码和证书校验。
- [ ] OpenVPN 3 引擎与单一 VpnService 生命周期整合。
- [ ] 引擎切换时明确 UI 状态与潜在断网。
- [ ] IKEv2/IPsec 与 OpenConnect 的可行性与许可评估。

## V0.5：智能管理
- [ ] 中国大陆规则集分流与 DNS 策略；避免 DNS、IPv6 泄漏。
- [ ] 主力/备用节点健康探测及退避、冷却时间。
- [ ] 按应用路由与可解释测速报告。
- [ ] 网络掉线后恢复与 Android 重启行为。

## 非功能验收
- 不伪造 VPN 可用状态、不无提示丢弃用户配置。
- 凭据本地加密，不出现在日志、崩溃分析和 CI。
- GitHub Actions 编译及测试通过；发布 APK 可在 Android 8+ 设备安装。
- 核心依赖许可合法兼容；UI 清晰告知各协议支持状态。
